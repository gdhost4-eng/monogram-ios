# Правила работы с проектом Monogram

## Сборка IPA

- Собирать проект и запускать GitHub Actions разрешено только после однозначной просьбы пользователя собрать, запустить сборку или получить IPA. Обычные изменения исходников, проверка кода и ответы на вопросы не являются таким разрешением.
- Перед каждым запуском сборки необходимо без отдельного подтверждения перевести репозиторий `gdhost4-eng/monogram` в публичный режим. Это нужно для бесплатного запуска macOS-исполнителя GitHub Actions.
- После запуска workflow не нужно ждать завершения сборки или отслеживать её статус. Репозиторий остаётся публичным; вернуть его в приватный режим можно только по явному запросу пользователя или по настроенной ежедневной автоматизации.
- Ежедневная проверка приватности запускается GitHub Actions в 06:07 по Москве и не зависит от включённого ПК. Она использует Secret `REPOSITORY_ADMIN_TOKEN`; токену требуется только доступ Administration: Write к этому репозиторию.
- Сборка запускается через workflow `.github/workflows/build.yml` на ветке `master`. Скачивать готовый IPA-артефакт и переносить его в локальные папки `build` или `builds` не нужно.
